## jq-failure-after-output

Input:

```json
{
  "name": "new_admin_user"
}
```

Exit status: `5`. Standard error is empty. Output:

```json
{
  "q": "new_admin_user",
  "act": "changed",
  "cols": {},
  "ep": ""
}
```

This case prepended a private `jq` substitute to PATH. It printed the recorded output, printed an
injected diagnostic to standard error, then exited 5. The helper suppressed that diagnostic and returned
5\. Row 3.1 must preserve stage failure propagation and retained prefix output when the stream adapter
replaces this helper; its separate cursor owner must retain the checkpoint on failure.

The substitute used for the capture:

```sh
#!/usr/bin/env bash
set -euo pipefail
printf '%s\n' '{"q":"new_admin_user","act":"changed","cols":{},"ep":""}'
printf 'injected jq failure\n' >&2
exit 5
```
